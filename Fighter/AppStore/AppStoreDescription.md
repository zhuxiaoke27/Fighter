# Fighter — Roguelike Card Game

## Subtitle
Build your deck. Conquer the spire. Master all three classes.

## Description (Chinese):
在这款杀戮尖塔风格的 Roguelike 卡牌游戏中，构建你的牌组、征服三层高塔！

【游戏特色】
- 47+ 张独特卡牌，三大职业各有专属卡组
- 25+ 种怪物与精英，策略搭配应对不同挑战
- 30+ 件遗物收集，打造专属战斗流派
- 15+ 种药水，关键时刻逆转战局
- 50+ 个随机事件，每次冒险都不一样
- 20 级飞升难度，无尽挑战等你征服
- 像素风角色动画，复古又精致的视觉体验
- 完整中文支持，本地化体验

【三大职业】
- 战士 — 高血量、回复型坦克
- 刺客 — 敏捷、毒药的暗影杀手
- 法师 — 元素魔法的掌控者

每次冒险都是独一无二的旅程！
